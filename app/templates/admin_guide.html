App 管理

在「App 管理」頁面可以新增、修改和刪除已註冊的 AI 應用程式。

  • 新增 App：填入 App ID、名稱、Redirect URI，系統會自動產生 client_secret（僅顯示一次，請立即複製）
  • 允許組織：指定哪些組織的員工可以存取此 App，留空表示不限制
  • 預設權限：當允許組織非空時，組織內的員工自動擁有此預設權限等級（無需逐一授權）。預設權限僅支援 Level 1（Read）和 Level 2（Read+Write），Level 3（Admin）必須逐人手動授權
  • Token 有效時間：設定使用者登入後取得的 JWT Token 有效小時數（1-720 小時，預設 12）
  • 刪除 App：刪除後該 App 的 OAuth 流程將失效，但已存在的使用者權限記錄不會自動刪除
新增 App 後產生的 Client Secret 僅顯示一次，請務必複製後安全保管。如果遺失，需要刪除 App 後重新建立。

權限管理

每個使用者需要被明確授權才能存取特定的 App。權限分為三個等級：

Level 名稱 Scopes 說明
1 Read read 僅可查看資料
2 Read + Write read, write 可查看及修改資料
3 Admin read, write, admin 完整權限，含 App 內部管理功能
  • 授權：選擇使用者、App 和等級後點擊「授權」即可
  • 撤銷：在權限列表中點擊對應的「撤銷」按鈕
  • 搜尋：可依使用者名稱或 App ID 模糊搜尋（支援部分匹配）
個人權限優先於組織預設權限。如果使用者同時有個人授權和組織預設權限，以個人授權為準。

使用者管理

在「會員管理」頁面可以查看所有已註冊的使用者帳號。

  • 重設密碼：系統會產生隨機新密碼，請複製後轉交給使用者
  • 刪除帳號：將同時刪除該使用者的帳號和所有 App 權限記錄（不可復原）

App Admin 指派

你可以指派員工為特定 App 的管理員（App Admin），讓他們協助管理該 App 的使用者權限。

  • App Admin 可以：管理其負責 App 的使用者權限（授權/撤銷）、編輯 App 設定（允許組織、預設權限、Token 有效時間）
  • App Admin 不能：新增/刪除 App、指派其他 Admin、查看其他 App 的權限
  • Level 3 自動同步：授予使用者 Level 3 權限時，該使用者會自動成為該 App 的 App Admin；降級或撤銷時自動移除（手動指派的不受影響）
  • 被指派的員工必須已有 AuthCenter 帳號才能登入管理後台

使用者註冊流程

新使用者需要透過註冊連結才能建立帳號：

  • 方式一：使用者在 App 登入頁面嘗試登入 → 系統偵測到未註冊 → 使用者點擊「申請註冊」 → Teams 通知管理員 → 管理員在 Dashboard 的「待處理註冊」產生連結
  • 方式二：管理員主動在 Dashboard 輸入員工帳號，直接產生註冊連結
註冊連結預設有效 24 小時。連結中包含一次性 token，使用者設定密碼後即完成註冊。

存取紀錄

「存取紀錄」頁面記錄使用者透過 AuthCenter 登入 App 並取得 Token 的歷史，包括：

  • 統計資訊：總存取次數、今日存取次數、今日活躍人數
  • 篩選功能：可依 App 或使用者名稱過濾
  • 記錄內容：時間、使用者名稱、App 名稱、IP 位址

操作紀錄

「操作紀錄」頁面記錄所有管理員的操作，包括：

  • App 新增/修改/刪除
  • 使用者權限授予/撤銷
  • App Admin 指派/移除
  • 密碼重設、帳號刪除
  • 註冊連結產生

每筆記錄包含操作者、動作類型、對象和時間戳記，可用於稽核和問題追蹤。
